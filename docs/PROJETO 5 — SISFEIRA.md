# PROJETO 5 — SISFEIRA (Web)

## Sistema Web de Gestão de Pedidos para Feira de Produtores Locais

**Tipo de sistema:** Aplicação Web (front-end + back-end)

## Contexto e Justificativa

Produtores da agricultura familiar do Amazonas não possuem canal digital para divulgar produtos e receber pedidos antecipados dos clientes da feira, gerando desperdício e limitando o alcance de vendas.

## Objetivo Geral

Desenvolver um sistema web para gestão de pedidos, catálogo de produtores e entregas de uma feira de produtores locais.

## Objetivos Específicos

- Permitir o cadastro de produtores e de seus produtos.
- Disponibilizar um catálogo de produtos por semana/feira.
- Permitir que o cliente realize pedidos on-line.
- Acompanhar o status do pedido até a entrega/retirada.

## Perfis de Usuário / Stakeholders

- Produtor(a) local
- Cliente/comprador(a)
- Organização da feira

## Requisitos Funcionais (RF)

- **RF01.** Cadastrar produtores e seus respectivos produtos.
- **RF02.** Cadastrar clientes/compradores.
- **RF03.** Disponibilizar catálogo de produtos por semana ou edição da feira.
- **RF04.** Permitir que o cliente monte um pedido (carrinho de compras).
- **RF05.** Confirmar o pedido e gerar comprovante para o cliente.
- **RF06.** Gerenciar o status do pedido (recebido, em preparação, entregue).
- **RF07.** Consultar o histórico de pedidos por cliente.
- **RF08.** Gerar relatório de vendas por produtor.
- **RF09.** Notificar o produtor sobre novos pedidos recebidos.
- **RF10.** Definir o ponto de retirada/entrega do pedido.

## Requisitos Não Funcionais (RNF)

- **RNF01. Desempenho:** carregar o catálogo de produtos em até 2 segundos.
- **RNF02. Segurança:** proteger os dados de clientes e produtores cadastrados.
- **RNF03. Usabilidade:** processo de pedido simples, em poucos cliques.
- **RNF04. Disponibilidade:** manter-se disponível nos dias e horários de maior demanda (dias de feira).
- **RNF05. Portabilidade:** layout responsivo, otimizado para uso em smartphones.
- **RNF06. Escalabilidade:** suportar picos de acesso em dias de feira sem perda de desempenho.
- **RNF07. Manutenibilidade:** catálogo de produtos administrável sem necessidade de programação.

## Componentes e Serviços Necessários para a Implementação

- Front-end web responsivo
- Back-end com API REST
- Banco de dados relacional
- Módulo de carrinho de compras
- Autenticação de usuários
- Serviço de notificações
